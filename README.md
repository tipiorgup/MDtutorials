# CoassemblyGromacs

I created two tutorials for you to try two different platforms for MD: Gromacs and OpenMM.
The base tutorial is this one: http://www.mdtutorials.com/gmx/lysozyme/01_pdb2gmx.html

I find OpenMM to have a nicer learning curve (if you are familiar with Python), GROMACS is a more widely used software and can give us broader options with MD.

Create a different enviornment for using OpenMM, remember to create them as:

conda create -n openmm

For OpenMM you will need to install:
openmm (conda install -c conda-forge openmm)
numpy
matplotlib
jupyter

You can use conda install or pip install. I would like you to give it a try by your own, if it gets too complicated I will send you a line command to copy and paste.

Remember to select in anaconda the environment you want to use.
